# 本机多源部署

## 启动

在项目根目录运行 `./start-panel.ps1`。后端使用独立的 `backend/.venv`，托管已编译的前端，地址为 `http://127.0.0.1:3018`。
启动器不抢占其他进程的端口；日志位于 `data/logs/panel.out.log`、`panel.err.log`，PID 记录在 `panel.pid`。未配置开机自启。

重新安装依赖：后端运行 `python -m uv sync --extra backtest --extra dev --extra legacy-cpu`；前端运行 `pnpm install --frozen-lockfile`、`pnpm build`。
Windows 子进程缺少 `PROCESSOR_ARCHITECTURE` 时，启动器会在确认系统为 X64 后补为 AMD64；不跳过 Polars CPU 检查。

## 凭据与路由

密钥只放在被 Git 忽略的 `.env` 或系统环境变量中：`TUSHARE_TOKEN`、`TICKFLOW_API_KEY`、`FUYAO_API_KEY`。
Codex 全局凭据文件的位置另记在用户全局指南中；项目不会自动读取该全局文件。全局文件更新后，需要同步项目配置并重启。

| 原始日线、复权事件 | Tushare |
| 实时行情、标准财务数据 | fuyao |

## Tushare

新增插件位于 `backend/app/plugins/tushare`。支持股票、指数、ETF 原始日线及股票/ETF 复权因子，具体接口受账户权限限制。
成交量保留为手，成交额从千元转换为元。累计复权因子按相邻交易日比值转换为除权事件，不能直接当作事件比值。
日线与复权进入原有 Parquet 存储和指标流水线。首次大范围同步逐标的调用，速度受账户频率限制；尚未进行全市场历史压力验证。

## 华泰 MCP

插件位于 `backend/app/plugins/huatai`，复用用户已存在的研究台 MCP runtime，不复制其凭据。项目 `.env` 需要：

- `HUATAI_PYTHON`：安装了原 MCP 依赖的 Python 可执行文件。
- `HUATAI_RUNTIME_ROOT`：包含 `src/desk/mcp_runtime.py` 的研究台根目录。
- `HUATAI_PROFILE`：已有 MCP 服务配置文件。

日线适配器只声明 A 股 `daily` 能力，显式将股转换为手，要求上游明确给出元/股单位；未知字段或单位会拒绝写入。
不能将其配置为实时行情源。其他资产类型交由宿主既有回退逻辑处理。
MCP 缓存位于 `data/huatai/cache/mcp`，复用原 runtime 的有效期、来源、获取时间和版本规则。
删除或移动原研究台、Python 或 MCP 配置会导致该连接失效。

## 多源研究页面

华泰现支持 `financial` 数据集，可在财务数据源设置中选择：核心指标、利润表、
资产负债表、现金流量表映射到选股器标准字段。金额为元，百分比为百分点，
保留真实报告期和发布日期；口径不符时拒绝写入。净利润同比使用归母口径。
目前仅取最新披露期（历史请求也只返回最新期并记录警告），不补历史多期或股本。
不适用于完整历史财务回测；全市场可用性以实际财务同步结果为准。

访问 `/local-research`，或侧栏“多源研究”：

- 华泰估值：按查询日期获取数据。
- 华泰财报、主营：最近一期，未将其未经核验的字段注入回测财务表。
- Tushare 龙虎榜：按日期和股票查询；没有上榜记录时返回空结果，属于成功无数据。
- 刷新按钮对华泰绕过有效缓存；Tushare 龙虎榜每次直接查询。

接口为 `POST /api/custom/local-research/query`，请求包含 `kind`、`symbol`、`day`、`refresh`。
研究类型仅允许 `valuation`、`financial`、`business`、`dragon_tiger`。

## 数据初始化范围

Tushare 另支持 `minute` 与 `financial`：个股分钟周期为 1/5/15/30/60m，
原始价格、北京时间，成交量从股转换为手，成交额为元；指数和 ETF 分钟拒绝请求。
分钟按 7 天窗口拉取。账户实测分钟限频为 1 次/分钟，限频时等待后最多重试两次；
因此不适合高频轮询或快速全市场分钟同步。未声明 `full_minute` 或五档盘口能力。
财务支持指标、利润表、资产负债表、现金流量表及历史报告期，股本暂不提供。
Tushare 财务每 20 只股票合并保存一次，异常日期记录隔离、单股请求失败记录后继续。
进度和异常明细保存在 `data/financials/*-sync-report.json`，财务概况页显示摘要；
存在异常时不更新该表的成功同步时间。已保存批次在进程中断后保留，
重新同步仍会重新请求历史数据，不属于财务下载断点续传。
三表仅采用合并累计原始报表，优先实际公告日期，金额元、比率百分点；
同一报告期多个版本只保留最近公告版本，不能据此声称具有完整修订版本回放能力。

Tushare 股票日 K 同步会逐只原子保存到 `data/daily_sync_resume`。
中断后重新发起相同数据源、股票列表和日期范围的同步，会复用完成的批次。
全部取齐并入库后删除本轮检查点；失败结果不缓存，成功的空结果也记录完成。
检查点不是正式行情数据，不参与指标计算。日期范围变化会重新取数；
本功能不包含自动重连调度、复权因子或其他数据源的断点续传。

本机已完成证券目录同步；以贵州茅台近一年日线、复权事件和指标计算完成端到端验证。
这只是安装验证数据，不是完整的全市场回测数据库；全市场选股前请在“数据”页完成所需范围同步。
新装策略库为空，需要自行创建或导入策略。

## 本机 Codex 网络

如果本机 Codex 登录有效但面板连接超时，可在 `.env` 配置
`AI_CODEX_PROXY_URL=http://127.0.0.1:7890`（按实际代理端口调整），然后重启后端。
该配置仅传给 Codex 子进程，不改变金融数据源的网络设置。使用期间须保持本机代理运行。


### Tushare 股本表

`shares` 使用 `daily_basic`，保留每日总股本、流通股本、自由流通股本；万股乘 10000 后统一为股。
沿用 `financial_history_start_date` 起点。`period_end` 为兼容股本表键而存储快照交易日，
不是季度报告期；同时保留 `trade_date` 和 `source=tushare.daily_basic`。
`announce_date` 留空，不虚构公告日；`available_date` 保守设置为快照日期下一自然日，
历史股本计算优先采用此字段，因此当天盘后公布的数据不会用于当天历史计算。
旧来源无 `available_date` 时继续使用原公告日/报告期规则。空或非法股本记录进入同步错误报告。
